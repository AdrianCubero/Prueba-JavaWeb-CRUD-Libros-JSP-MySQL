Sistema de Gestión de Libros
Aplicación web desarrollada en Java utilizando JSP, Servlets, JDBC y MySQL.

Funcionalidades
Crear libros
Consultar libros
Editar libros
Eliminar libros
Mostrar imágenes mediante URL
